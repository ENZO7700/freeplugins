# **App Name**: Expresívny Navigátor

## Core Features:

- Animované Intro: Animované intro na úvodnej obrazovke s efektnými prechodmi a pútavou grafikou.
- Responzívny Layout: Responzívny layout, ktorý sa prispôsobuje rôznym veľkostiam obrazoviek a zariadení.
- Prepínanie Tmy/Svetla: Prepínanie medzi tmavým a svetlým režimom s plynulými prechodmi a možnosťou automatického prispôsobenia podľa času.
- Toast Notifikácie: Interaktívne notifikácie (toasty) pre spätnú väzbu používateľovi (úspech, varovanie, chyba).
- Animované Prechody Strán: Animované prechody medzi stránkami pre plynulý a vizuálne atraktívny zážitok.
- Paralax Efekty: Jemné paralax efekty pri scrollovaní pre zvýšenie hĺbky a interaktivity.
- Adaptívny animácie: AI nástroj, ktorý dokáže odvodzovať na základe správania sa používateľa a automaticky nastavovať prvky a animácie aplikácie pre optimálny výkon.

## Style Guidelines:

- Primárna farba: Sýta fialová (#9F43D1), ktorá evokuje kreativitu a modernosť.
- Farba pozadia: Jemná sivá (#26272B) pre elegantný tmavý režim.
- Akcentujúca farba: Svetlá modrá (#4DB9E7) na interaktívne prvky a upozornenia.
- Písmo pre nadpisy: 'Poppins' (sans-serif) pre moderný a svieži vzhľad.
- Písmo pre telo textu: 'PT Sans' (sans-serif), čitateľné a univerzálne pre rôzne časti aplikácie.
- Použitie framer-motion pre všetky animácie, prechody strán, efekty hoveru a mikrointerakcie.
- Responzívny dizajn pomocou Tailwind CSS, optimalizovaný pre mobilné zariadenia a rôzne veľkosti obrazoviek.
